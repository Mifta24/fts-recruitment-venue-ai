# User Flow

```text
Opening screen → Enter venue → 01 Welcome
   ├─ 02 Spaces → space detail → "Book this space" ─┐
   ├─ 03 Facilities → facility detail               │
   ├─ 04 Venue information                          ├→ 05 Book your event → reference number
   ├─ 06 Venue team (WhatsApp / phone / email)      │      → WhatsApp / phone / email hand-over
   └─ AI Coordinator chat (any step) ───────────────┘
```

1. The organiser lands on the opening screen and enters the venue (or picks one when several are published).
2. The pipeline bar offers the five sections. Choosing one closes the shutters, the coordinator announces the next step and the page changes. A menu pick also hands a starter question to the coordinator.
3. On a space page the organiser can compare spaces, look at the gallery, and start a booking with that space preselected.
4. The booking wizard asks for dates, crowd, space, details (name, company, event type, contact) and shows a summary with the exact total.
5. The result is a reference number (`BK-XXXXXX`) and ready-made WhatsApp / phone / email links that carry the summary to the venue team.
6. At any time the organiser can chat. The coordinator knows which step, space, facility or booking draft is on screen.
7. When the coordinator cannot or should not answer, it hands the conversation over to staff, who reply from the admin panel.
